
# 📚 Library Management System

A Python-based Library Management System using SQLite.

## ✨ Features
- Add new books
- View all books
- Search books by title, author, ISBN, or category
- Update book details
- Delete books
- Issue and return books
- Track borrowing history
- Generate library reports

## 🛠️ Technologies Used
- Python 3
- SQLite
- SQL

## ▶️ How to Run
1. Install Python 3.
2. Download `library.py` from this repository.
3. Open a terminal in the folder containing the file.
4. Run:

   `python library.py`

## 📂 Project Files
- `library.py` — Main program
- `README.md` — Project documentation
- `library.db` — Database created automatically when the program runs

## 🎯 Learning Outcomes
- Python functions and loops
- Database operations (CRUD)
- SQL queries
- Exception handling
- SQLite database management
